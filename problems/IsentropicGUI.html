Assumptions used by this explorer

AdiabaticQ̇ = 0
Working fluidAir, treated as an ideal gas
Kinetic energyΔKE = 0
Potential energyΔPE = 0
Flow modelSteady-state, steady-flow (SSSF)
PortsSingle inlet, single outlet (SISO)
Under these assumptions, a feasible adiabatic compressor has s₂a − s₁ = sgen ≥ 0. For the isentropic comparison state, s₂s = s₁.

Property-model transparency

CSH: fixed values are R = 0.287 kJ/(kg·K), cp = 1.005 kJ/(kg·K), cv = 0.718 kJ/(kg·K), and k = 1.400. These values are intentionally not editable.

VSH: uses linear interpolation of the embedded A-21 ideal-gas air table from 200 K to 2250 K. No extrapolation is performed.

Specific volume: both models use the ideal-gas relation v = RT/P.

Entropy: consistency is checked from entropy differences. In Supported Entry, the displayed entropy datum is aligned to the A-21 standard-state entropy convention; for CSH, s(300 K, 100 kPa) is anchored at 1.70203 kJ/(kg·K) so CSH and VSH can share one plotting scale.

Purpose: this is a visualization/checking tool, not a property-state solver. It does not replace inconsistent student inputs with corrected values.
