Property model transparency

Water properties use A-4/A-5 saturation data, A-6 superheated-water data, and A-7 compressed-liquid data with linear interpolation and no extrapolation. The browser model follows the same table-driven philosophy as the thermoState tool. When compressed-liquid coverage is insufficient for a pump plotting coordinate, a documented incompressible approximation is used rather than extrapolating.

This explorer is a visualization aid rather than a full cycle solver. Use independent analysis to determine component heat transfer, work interactions, and thermal efficiency.

Feasibility colors: green means the configured cycle can be represented by the current table model; yellow means the cycle is feasible but a phase/design condition deserves attention; red means the combination is invalid or outside supported data. Yellow is not an automatic engineering rejection.
